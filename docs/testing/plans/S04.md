## The page rule for a roll

CSS has no "as long as the content" page length, and one length alone means a square page. So the dialog measures the receipt it shows and sets `@page { size: <roll>mm <receipt height + 6>mm; margin: 0; }` just before printing; A4 length is the fallback when nothing can be measured. The content is 72 mm wide on an 80 mm roll and 48 mm on a 58 mm roll.
