## Decisions for this task
- **i18n:** add `i18next` + `react-i18next` (allowed). Move B7's keys into namespaced JSON files under `src/i18n/locales/{ar,en}/`. The language switch sets `<html lang dir>` and the Radix `DirectionProvider`, and is remembered per viewer. Arabic is the default. Numbers and dates use `Intl` with the active locale through one `src/lib/format.ts` (money is formatted from the contract's decimal **string**; never `parseFloat` for maths).
- **Data table:** `@tanstack/react-table` (allowed). Server-side pagination shape = the contract's paginated response.
- **Forms:** `react-hook-form` + `@hookform/resolvers/zod` (allowed); fields take a contract zod schema and show translated errors.
- **Toasts:** use one small library (`sonner` allowed) or a Radix-based toast; no `alert`/`confirm` anywhere (add an ESLint `no-alert` error rule).
- **Permissions (D18):** this task builds `usePermissions()` (react-query on `GET /api/me/permissions`, typed by the contract; the server half is F06, wave 4, built against the same contract) and the route guard `<RequirePermission permission="…">` that renders a 403 page for direct URL access. F06 (B10) later adds `useCan`, `<Can>` and branch-access hooks **on top of** your `usePermissions`. Don't build those.
- **Branch switcher:** branches come from the contract `me` response (`/api/auth/me`). The selected branch is stored in the client store and sent as a header only if the contract defines one. If it doesn't, keep it client-side and say so.
- **frontend-design** isn't installed: follow `design.md`.
